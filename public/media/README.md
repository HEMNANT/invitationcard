# Couple media goes here

Drop the couple's real photographs and videos in this folder, then point to them in
`src/config/wedding.config.js` (for example `/media/hero.mp4`, `/media/bride.jpg`).

Recommended for slow mobile networks:
- Photos: 1600px on the long edge, JPEG/WebP, under ~300 KB. Optionally provide `{ sm, md, lg }` sizes.
- Videos: H.264 MP4 (add a WebM if you like), 720p portrait or 4:5, 8–15 seconds, under ~4 MB,
  with a `poster` image so something appears immediately.
